🔍 구글 리뷰 자동 불러오기 선택

    

      비워두셔도 괜찮아요. 기록 화면의 「구글 리뷰 보러가기」 버튼은 키 없이도 잘 동작해요.

      키를 넣으면 별점과 리뷰가 앱 안으로 바로 들어와서, 마음에 드는 코멘트만 눌러 팁에 담을 수 있어요.
    

    
    
    

      키는 이 브라우저에만 저장돼요. 발급은

      에서 Places API (New) 를 켜면 돼요. 필요하시면 같이 해드릴게요 🙂
