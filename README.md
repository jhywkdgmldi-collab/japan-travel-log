# 🇯🇵 일본여행 기록장

여행 다니면서 **어디 갔고 · 뭘 했고 · 얼마 썼는지** 한 번에 남겨두고,
돌아와서 **블로그 글 / 인스타 캡션 / 릴스 자막으로 바로 뽑아 쓰는** 여행 기록 앱이에요.

설치할 것도, 회원가입도 없어요.

## 📱 폰에서 바로 쓰기

**https://jhywkdgmldi-collab.github.io/japan-travel-log/**

폰 브라우저로 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.
(아이폰: 공유 → 홈 화면에 추가 / 안드로이드: ⋮ → 홈 화면에 추가)

> 기록은 **그 기기의 브라우저 안에만** 저장돼요. 인터넷으로 나가지 않아요.
> 그래서 폰과 노트북은 서로 다른 기록장이에요 — 옮길 땐 백업 파일을 쓰세요.

## 🚀 시작하기

**방법 1 (추천)** — `실행하기.bat` 더블클릭
→ 브라우저가 자동으로 열려요. 검은 창은 켜둔 채로 두세요.

**방법 2** — `index.html` 을 그냥 더블클릭
→ 대부분 잘 되는데, **「📍 지금 내 위치」 버튼만 안 눌려요.**
   (브라우저 보안 규칙상 `http://localhost` 나 `https://` 에서만 위치를 줘요)

**방법 3 (여행 중 폰으로 쓰고 싶다면)** — 인터넷에 올리기
```bash
vercel
```
`여행개발` 폴더에서 위 명령 한 번이면 주소가 나와요.
그 주소를 폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요. 위치 버튼도 잘 되고요.

## 📝 이렇게 써요

| 탭 | 하는 일 |
|---|---|
| **📝 기록** | 장소·금액·한줄기록·사진·영수증 남기기. 날짜별로 자동 정리돼요 |
| **🗺 지도** | 다닌 곳에 핀이 찍히고 동선이 선으로 이어져요. 날짜별로 볼 수 있어요 |
| **💰 정산** | 총액·1인당·하루평균, 카테고리별/날짜별/결제수단별, 영수증 빠진 항목 체크 |
| **📤 내보내기** | 블로그 마크다운 · 인스타 캡션 · **🎬 릴스 클립 자막** · 일정표 · 엑셀 CSV |
| **⚙ 설정** | 여행 제목·기간·환율·인원. **환율은 나중에 고쳐도 전체가 다시 계산돼요** |

### 기록 남기는 순서 (여행 중엔 30초면 끝나요)
1. 하단 **＋ 새 기록 남기기**
2. 장소 이름 적고 → **검색** 누르면 위치가 자동으로 잡혀요
   - 안 찾아지면 **📍 지금 내 위치** 또는 **🗺 지도에서 찍기**
3. 종류(🍜식사 ☕카페 🚆교통 …) 고르고 금액 입력 (¥ 기본, ₩로도 바꿀 수 있어요)
4. **세 가지 글칸**을 목적에 맞게 나눠 써요 👇
5. 🧾 영수증 찍기 / 🖼 사진 추가
6. 저장

### ✍️ 글칸 세 개, 이렇게 나눠 써요

| 칸 | 무엇을 | 어디에 쓰이나 |
|---|---|---|
| ✨ **이곳의 한줄** | 장소를 한 문장으로 | 블로그 **소제목**, 릴스 **자막**으로 그대로 |
| 📝 **한 줄 기록** | 그때 내 느낌·감상 | 블로그 **본문**, 인스타 캡션 |
| 💡 **참고 · 팁** | 리뷰에서 본 장단점·꿀팁 | 블로그 "참고" 목록, 다음에 갈 때 |

> 예) 이곳의 한줄 `40분 줄 서도 아깝지 않은 라멘`
> · 한 줄 기록 `국물이 진짜… 다음에 또 옴`
> · 참고·팁 `옥상 식권기로 먼저 주문 / 혼밥 자리라 혼자가 편해요`

### 💡 구글 리뷰 참고하기
「참고 · 팁」 칸 위의 **🔍 구글 리뷰 보러가기** 를 누르면 그 장소의 구글맵이 열려요.
쓸 만한 코멘트를 복사해 팁 칸에 붙여넣으면, 내 기록과 남의 팁을 같이 보게 돼요.

> **자동으로 불러오고 싶다면**: 설정 탭에 Google Places API 키를 넣으면
> **✨ 리뷰 불러오기** 버튼이 생겨요. 별점·리뷰가 앱 안에 뜨고, 누르면 팁 칸에 바로 담겨요.
> (키 발급은 구글 클라우드 콘솔에서 Places API (New) 를 켜면 돼요)

### 💱 환율은 기록할 때마다 따로 저장돼요
여행 중엔 환율이 매일 달라지죠. 그래서 **기록 하나하나에 그때 환율이 붙어서** 저장돼요.
앱을 열면 오늘 환율을 자동으로 가져오고, 나중에 카드 청구서 환율로 **한 번에 통일**할 수도 있어요
(설정 → 모든 기록에 기본 환율 적용하기).

## 🗺 구글맵 연동은 이렇게

공식 구글맵 API는 카드 등록·키 발급이 필요해서, **키 없이 되는 방식**으로 붙였어요.

| 기능 | 위치 |
|---|---|
| 장소 하나를 구글맵에서 열기 | 기록 카드의 `📍 구글지도` 태그 |
| 하루 동선을 구글맵 길찾기로 열기 | 지도 탭 → **구글맵 동선 열기** |
| **내 지도(마이맵)로 만들기** | 지도 탭 → **KML 저장** → [google.com/mymaps](https://www.google.com/mymaps) 에서 `새 지도 만들기 → 가져오기` |

> KML로 만든 마이맵은 **블로그에 그대로 삽입**할 수 있어요. 여행 후기 글에 지도 하나 박아두면 완성도가 확 올라가요.

## ⚠️ 꼭 알아두실 것

- 기록은 **이 브라우저 안에만** 저장돼요. 서버로 안 나가요 (그만큼 안전해요)
- 그래서 **브라우저 기록 삭제 / 다른 기기 = 기록 없음** 이에요
- 👉 여행 끝나면 **📤 내보내기 → 백업 저장** 으로 `.json` 파일 꼭 받아두세요
- 폰에서 쓰다가 노트북으로 옮길 때도 이 백업 파일로 **불러오기** 하면 그대로 옮겨져요
- 사진은 자동으로 작게 줄여서 저장되지만, 브라우저 저장 공간(약 5MB)은 한계가 있어요.
  ⚙설정 탭에서 지금 얼마나 쓰고 있는지 볼 수 있어요
